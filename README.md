# Генератор случайных цитат

Консольное приложение для просмотра вдохновляющих цитат с категориями, избранным и возможностью поделиться в мессенджерах.

## Возможности

- 🌟 Цитата дня — разная каждый день
- 📂 7 категорий: Мотивация, Мудрость, Успех, Жизнь, Творчество, Любовь, Юмор
- ⭐ Избранное — сохранение понравившихся цитат
- 📤 Поделиться — Telegram, WhatsApp, копирование в буфер
- 📊 Статистика запусков
- 🎲 Случайная цитата из выбранной категории

## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/UZer88/quote-generator.git
cd quote-generator
```

2. Создайте виртуальное окружение:
```bash
python -m venv venv
venv\Scripts\activate  # Windows
source venv/bin/activate  # Linux/Mac
```

3. Запустите программу:
```bash
python quote.py
```

## Требования

Python 3.8 или выше
Дополнительные библиотеки не требуются (только встроенные модули)
